# ⚡ Wisnu Cyber-Cloud Console v3.0

An automated cloud provisioning engine built with Python and Boto3 SDK for localized infrastructure management. Developed specifically as an independent final assignment for the Cloud Computing Course.

## 🛠️ System Blueprint
Unlike public repositories, this project isolates AWS automation scripts using object-oriented program execution (OOP Class Structures) to maintain cleaner code delivery.

### Configured Matrix
- **Core Engine**: Python 3.11+
- **Infrastructure SDK**: AWS Boto3 Core
- **Target Handler**: MiniStack / LocalStack Simulator (Active Interface: `http://localhost:4566`)

## 🚀 Execution Guide
To launch the deployment engine inside your local cluster runtime, clone the file and use the command interpreter below:

```bash
# Installing the localized network matrix
pip install boto3 pandas

# Firing up the console core
python app_engine.py
```
